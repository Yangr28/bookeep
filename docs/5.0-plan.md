# Bookeep v5.0 开发方案

> 本文档用于跨电脑交接。另一台电脑 clone/pull 后，在新会话中让 AI 读本文件即可接续开发。

## 项目交接要点

- 技术栈：Capacitor + React 18 + TypeScript + Vite + Tailwind + zustand（分 slice）+ i18next
- **双语必须同步改**：`src/i18n/locales/zh-CN.json` 和 `en-US.json` 每个新 key 两边都要加
- 设计规范：
  - 卡片用 `.card` 类；内边距 p-4 / p-3.5；列表间距 space-y-2.5
  - 文字防溢出：`truncate` + `min-w-0` + 必要时 `whitespace-nowrap`
  - 颜色一律用 CSS 变量（`var(--ink)`、`var(--ink-2)`、`var(--primary)`、`var(--expense)`、`var(--card)`、`var(--paper)`、`var(--line)` 等），深浅色自动适配
  - 弹层用 createPortal 到 body + `.sheet` 样式
- 发版流程（纯 Web 热更新）：
  1. 改 `package.json` 的 version + `.env` 的 APP_VERSION（保持一致）
  2. `node scripts/release-update.mjs` 构建打包
  3. `gh release create v<版本号> release-assets/dist_v<版本号>.zip release-assets/update.json --title "v<版本号>" --notes "更新说明"`
  4. `git commit` + `git push`（GitHub 连接常抖动，push 失败用 40s 间隔循环重试）
- 原生改动必须额外升 `android/app/build.gradle` 的 versionCode/versionName 并打 release APK，和热更新包传同一个 Release
- 环境：Windows + PowerShell。不要用 `&&`（用 `;`）；不要用 Set-Content 改 JSON/.env（会引入 BOM）
- 当前版本：v4.16.10，最新提交 3a67118

## 三项功能方案

### ① 首页自定义（纯 Web，可热更新）

- store 新增配置 `homeCards: { id: string; visible: boolean; order: number }[]`，持久化到本地
- Dashboard 五个区块拆为子组件：本月概览 / 预算 / 快捷工具 / 今日收支 / 近三日记录，按配置排序、按 visible 显隐
- 设置页加「首页管理」入口：每卡开关 + 上下移动按钮（拖拽可选，注意包体积）
- 默认值保持现有顺序，兼容老用户

### ② 年度账本（纯 Web，可热更新）

- 新建 `src/pages/YearReview.tsx`，从 `transactions` 聚合全年数据
- 内容：年度收支曲线（复用 recharts）、月度对比、Top 支出分类、最大单笔、月均消费
- 统计页加入口；路由在 App.tsx 注册
- 年终分享图可用 SVG 自绘导出（可选二期）

### ③ 支付通知监听自动记账（原生 + Web，整包发版）

1. 原生：android/ 下实现 Capacitor 插件 + `NotificationListenerService`，过滤微信（com.tencent.mm）、支付宝（com.eg.android.AlipayGphone）等包名，`notifyListeners` 把通知 title/text 推到 JS
2. 权限：跳 `Settings.ACTION_NOTIFICATION_LISTENER_SETTINGS`，提供授权状态检测
3. Web 层：通知解析规则库（正则模板：微信「微信支付」、支付宝「付款成功 ¥x.xx」、银行 App），提取金额/商户/时间 → 复用 `addTransaction` 入账
4. 第一版先弹「确认入账」卡片，稳定后再加全自动开关
5. 分类匹配复用 `smartParser` / `findCategoryByIdentifier` 关键词逻辑
6. 国产 ROM 需引导用户加后台白名单/自启动
7. 发版：升 versionCode + Android Studio 打 APK

## 发布顺序

1. ① + ② 合发 **v5.0.0**（热更新）
2. ③ 单独发 **v5.1.0**（整包 APK + 热更新）
